# WP清書

Markdown-based notation → convert to WordPress block format → paste into the post screen. A single-page tool.

- Published at: https://claude.ai/artifact/NLLV7Ez3uakrKMKwFpyeZ8
- The converter is the section between `CONVERTER_START` and `CONVERTER_END` in `index.html`
- Output uses core blocks only (no plugins or theme required). Confirmed on WordPress 7.1 that all blocks pass block validation and expand into blocks on paste
